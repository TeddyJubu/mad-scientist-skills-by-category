## Installation

```bash
# Install individually
npm install @mad-scientist/media-lifestyle   # or: pnpm add @mad-scientist/media-lifestyle

# Or symlink into your Hermes skills folder
ln -s $(pwd)/skills ~/.hermes/skills/9-media-lifestyle
```
