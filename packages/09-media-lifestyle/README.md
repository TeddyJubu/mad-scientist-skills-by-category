# Media Lifestyle Skills
**Package:** `@mad-scientist/media-lifestyle` | **3 Skills** | Version 1.0.0

---

## What This Package Does

Weather, audio, YouTube transcripts, and media utility workflows

## Skills In This Package

### 1. fish-audio-tts
**Folder:** `skills/fish-audio-tts`

fish-audio-tts lets the user convert text into natural-sounding speech using the Fish Audio API, which is useful for creating voiceovers, audio content, or AI narration without needing a recording studio or voice actor.

### 2. weather
**Folder:** `skills/weather`

weather lets the user get current weather conditions and forecasts for any location without needing an API key, which is useful when they want a quick weather check for a property site, a listing area, a travel decision, or any planning that depends on weather conditions.

### 3. youtube-content
**Folder:** `skills/youtube-content`

Fetch YouTube video transcripts and transform them into structured content (chapters, summaries, threads, blog posts).

## Agent Install

```bash
npm install @mad-scientist/media-lifestyle
```

Or copy the `skills/` directory into your agent skills root.
