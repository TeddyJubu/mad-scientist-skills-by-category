# Software Development Skills
**Package:** `@mad-scientist/software-development` | **1 Skill** | Version 1.0.0

---

## What This Package Does For You

This package turns your AI agent into a senior software engineer. It can review code for bugs and security problems, help debug issues, plan how to build new features, and walk you through building software the right way with tests that prove it works.

Whether you're building something new, maintaining existing systems, or reviewing someone else's code — this package helps you move faster without breaking things.

---

## Skills In This Package

### 1. Software Development (Full Suite)
**What it does:** A comprehensive suite of development skills covering the entire software lifecycle:

**Code Review** — Reviews any codebase and gives a detailed report of bugs, security issues, performance problems, and code quality concerns. Uses industry-standard security scanning.

**What to say:**  
> "Review this Python script and tell me if there are any security vulnerabilities"

**What you get:** A detailed code review report with severity ratings (Critical/High/Medium/Low) for each issue found, plus specific fix recommendations.

---

**Debugging** — Takes an error message or unexpected behavior and walks through finding the root cause systematically, not just guessing at fixes.

**What to say:**  
> "My script keeps crashing with 'Connection refused' errors when trying to connect to the API — debug this"

**What you get:** Root cause identified, with the exact line in your code causing the problem and a verified fix.

---

**Test-Driven Development (TDD)** — Helps you build software by writing tests first, before the code. The tests prove the code works correctly. Used for critical code that cannot fail.

**What to say:**  
> "Help me build a function that calculates offer price using TDD — write the tests first"

**What you get:** A complete test suite written first, then the implementation, with all tests passing.

---

**Planning & Architecture** — Helps you plan how to build new features or applications. Walks through structure, tech stack choices, and implementation order.

**What to say:**  
> "I want to build a web app that lets investors track their deal pipeline — help me plan the architecture"

**What you get:** A complete project plan with recommended tech stack, database structure, key features, and the order to build things.

---

**Systematic Debugging** — A structured 4-phase approach to debugging: understand the problem, find the root cause, fix it, and verify it stays fixed.

**What to say:**  
> "My AI agent keeps losing connection to the database every 24 hours — debug this systematically"

**What you get:** A structured debugging report with each phase documented, root cause identified, fix applied, and verification steps.

---

**Spike Investigations** — Quick throwaway experiments to validate an idea before committing to building it. Tests whether something is even possible before investing time.

**What to say:**  
> "I want to know if I can use AI to automatically transcribe voicemails — do a spike to see if this is technically feasible"

**What you get:** A feasibility report with what worked, what didn't, and a recommendation on whether to proceed.

## How To Use This Package

### Installation
```bash
npm install @mad-scientist/software-development
```

Or symlink into your Hermes skills folder:
```bash
ln -s $(pwd)/skills ~/.hermes/skills/software-development
```

### Quick Start
```
skill_view(name="software-development")
```
