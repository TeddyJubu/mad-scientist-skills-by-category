# Communication Skills

**Package:** `@mad-scientist/communication`
**Version:** 1.0.0
**Category:** 08-communication

Discord bot control and server management for team communication.

## Skills Included (1)

```
  - discord/
```

## Installation

```bash
# Install individually
npm install @mad-scientist/communication   # or: pnpm add @mad-scientist/communication

# Or symlink into your Hermes skills folder
ln -s $(pwd)/skills ~/.hermes/skills/8-communication
```

## Usage

Each skill in `skills/` has its own `SKILL.md` with usage instructions. Load via your agent:

```
skill_view(name="skill-name")
```
