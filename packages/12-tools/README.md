# Tools Skills
**Package:** `@mad-scientist/tools` | **31 Skills** | Version 1.0.0

---

## What This Package Does For You

This is the utility belt for advanced users. It includes skills for training AI models, hosting game servers, controlling smart home devices, managing GitHub repositories, automating your CRM, and more. These are specialized capabilities for when you need very specific technical jobs done.

---

## Skills In This Package

### AI & Machine Learning

**MLOps** — Deploys and manages machine learning models in production. Takes a trained model and puts it to work in a real system where it can make predictions or decisions.

**What to say:**  
> "Deploy this fine-tuned AI model to production so my agents can use it"

**What you get:** Model deployed to an API endpoint your agents can call, with monitoring set up for performance tracking.

---

**Inference.sh** — Runs AI inference (making predictions with an AI model) on dedicated GPU servers. For when you need fast AI responses without running the model yourself.

**What to say:**  
> "Run this text through my custom sentiment analysis model and tell me if it's positive or negative"

**What you get:** The model's prediction, e.g., "Positive (92% confidence)"

---

**Unsloth (Fine-tuning)** — Fine-tunes AI models on your own data — makes a general AI model understand your specific business, industry, or style. For creating specialized AI that knows your business cold.

**What to say:**  
> "Fine-tune a model on all my past email responses so it can write in my voice"

**What you get:** A custom AI model trained on your data, ready to use for generating on-brand content.

---

**Axolotl & TRL (LLM Training)** — Advanced LLM training frameworks for supervised fine-tuning, RLHF, DPO, and GRPO training. For when you need to train a language model from scratch or significantly improve one.

**What to say:**  
> "Help me set up a DPO training run to improve my model's refusal behavior"

**What you get:** Training pipeline configured, with instructions for running and evaluating the training.

---

**vLLM (Model Serving)** — Deploys large language models at high throughput for production use. For running your own ChatGPT-equivalent on your own servers.

**What to say:**  
> "Set up a vLLM server to run Llama 3 on my GPU server"

**What you get:** A running LLM API server, ready to handle thousands of requests per hour.

---

**Whisper (Speech Recognition)** — Transcribes speech to text with OpenAI's Whisper model. Handles multiple speakers, accents, and noisy audio.

**What to say:**  
> "Transcribe this recording of my contractor walkthrough"

**What you get:** Full text transcript of the audio.

---

**CLIP (Image + Text)** — Connects images and text in AI — used for image classification, similarity search, and building visual search tools.

**What to say:**  
> "Find all images in this folder that match the description 'modern kitchen'"

**What you get:** List of matching images ranked by similarity score.

---

**Segment Anything (SAM)** — Cuts out objects from images automatically. Upload any image and tell it what to cut out — works on anything.

**What to say:**  
> "Cut the house out of this photo so I can put it on a different background"

**What you get:** The house as a transparent PNG, isolated from the original background.

## How To Use This Package

### Installation
```bash
npm install @mad-scientist/tools
```

Or symlink into your Hermes skills folder:
```bash
ln -s $(pwd)/skills ~/.hermes/skills/tools
```
