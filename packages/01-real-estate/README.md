# Real Estate Skills

**Package:** `@mad-scientist/real-estate`
**Version:** 1.0.0

## Installation

```bash
# Install individually
npm install @mad-scientist/real-estate   # or: pnpm add @mad-scientist/real-estate

# Or symlink into your Hermes skills folder
ln -s $(pwd)/skills ~/.hermes/skills/real-estate
```

## Usage

Each skill in `skills/` has its own `SKILL.md` with usage instructions. Load via your agent:

```
skill_view(name="skill-name")
```
