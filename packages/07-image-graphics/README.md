## Installation

```bash
# Install individually
npm install @mad-scientist/image-graphics   # or: pnpm add @mad-scientist/image-graphics

# Or symlink into your Hermes skills folder
ln -s $(pwd)/skills ~/.hermes/skills/7-image-graphics
```

## Usage

Each skill in `skills/` has its own `SKILL.md` with usage instructions. Load via your agent:

```
skill_view(name="skill-name")
```
